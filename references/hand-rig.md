# 手部重建与指骨绑定

## 1. 建立腕部坐标系

不要凭感觉放手。从原袖口截面反推：

```python
class HandFrame:
    def __init__(self, sign):
        self.sign   = sign
        self.origin = Vector((sign*.468, -.036, .969))                 # 手腕原点
        self.axis   = Vector((sign*.690, -.230, -.686)).normalized()   # 前臂向指尖
        front       = Vector((-sign*.270, -.953, .126))                # 身体前方参考
        self.dorsal = (front - self.axis*front.dot(self.axis)).normalized()  # 手背法向
        self.span   = sign*self.axis.cross(self.dorsal)                # 掌心横向
        self.center = self.origin + self.span*.0112 - self.dorsal*.0015
        self.cuff_cut = .010
```

`point(u, v, w)` 把局部坐标映射回世界：`center + u*axis + v*span + w*dorsal`；`local(co)` 是逆变换。左右手共用一套代码，靠 `sign` 镜像 `span`。

**为什么要三轴**：手不是轴对齐的。用世界 XYZ 做放样，手指会朝错误方向生长；用腕部三轴，五指的弯曲方向、指甲朝向、袖口切口自动一致。

## 2. 切掉旧手，补出袖口

1. 用 BMesh 清理重复点（`dist=1.2e-5`）与退化边。
2. 以 `plane_co = point(cuff_cut)`、`plane_no = axis` 做 `bisect_plane`，`clear_outer=True` 切掉手。
3. 收集切口边界边，正常情况下应得到约 120 条边。少于 20 条说明切面穿错了位置。
4. 沿切边做三层内折：缩放 `0.89`（袖口外翻）、`0.71`（袖口内壁）、`0.60`（里布），每层沿轴退 `0.016 / 0.015 / 0.002`。
5. 每层用原始边环顺序建四边形，法线统一重算，避免出现反面。

袖口、手、骨轴必须用同一组过渡函数，否则弯腕时袖口与手之间会露缝。

## 3. 掌部放样

沿 `u` 给 8 个截面（`u, 半宽, 半厚, v偏移, w偏移`）：

```python
(-.008,.027,.021, 0.,0.), (.008,.0245,.019, 0.,0.), (.030,.027,.0165,-.003,.000),
(.049,.031,.0165,-.001,.001), (.069,.0345,.015,-.001,.000), (.084,.034,.012,-.002,.001),
(.093,.026,.009,-.004,.001), (.098,.015,.0055,-.006,.001)
```

每个截面用 28 个角度采样，用超椭圆控制方圆：

```python
v = half  * copysign(abs(sin(a))**.81, sin(a))   # 手掌宽而扁
w = thick * copysign(abs(cos(a))**.72, cos(a))   # 掌心略平
```

再叠加两处局部体积：大鱼际 `5.7 mm` 高斯（`u≈.048, v≈.019`，只作用于掌心侧）、掌指关节脊 `1.6 mm`（`u≈.081`，四个指根位置）。

用 Catmull-Rom 在截面间插值（每段 4 步），得到光滑掌面。

## 4. 五指放样

每指 4 个骨点 `(u, v, w, radius)`，四点分别对应掌指关节、近节、中节、末节：

```python
'Index':  ((.072,.025,.001,.0099),(.104,.029,.000,.0082),(.126,.032,-.008,.0070),(.144,.034,-.018,.0057)),
'Middle': ((.077,.008,.003,.0102),(.113,.008,.000,.0088),(.136,.008,-.009,.0074),(.158,.010,-.021,.0060)),
'Ring':   ((.075,-.012,.001,.0094),(.104,-.014,-.003,.0078),(.127,-.017,-.013,.0069),(.149,-.019,-.026,.0057)),
'Little': ((.065,-.028,-.002,.0084),(.092,-.033,-.006,.0072),(.112,-.036,-.016,.0060),(.130,-.038,-.027,.0051)),
'Thumb':  ((.039,.019,-.009,.0122),(.062,.040,-.010,.0105),(.081,.053,-.019,.0085),(.101,.050,-.028,.0071)),
```

要点：

- 指尖不要直接收成尖。沿末节切向追加 4 段收口：`(0.33, r*0.90) (0.63, r*0.67) (0.88, r*0.37) (1.02, r*0.095)`，指尖才是圆钝的。
- 每节 16 边，`inset = 0.83`（拇指 0.88），让手指截面略扁于正圆。
- 拇指是例外：额外接一个起点 `(.018,.007,-.006,.0112)` 融进掌面，否则虎口会出现平切凸棱。
- 弯曲方向靠骨点自身的 `w` 递减实现（末节比近节低 1–2 cm），不要靠后期旋转。

## 5. 合并、融合、减面

```python
palm.data.remesh_voxel_size = .00118    # 1.18 mm 体素
bpy.ops.object.voxel_remesh()
# 平滑
modifier.factor = .58; modifier.iterations = 5
# 减面
ratio = min(1., 2900 / len(loop_triangles))
```

顺序不能换：**融合 → 平滑 → 减面**。先减面会把指根缝隙放大成裂缝，之后再也补不回来。每只手控制在约 2,900 三角形。

## 6. 指甲

不要手工摆甲片。用射线贴到真实曲面上：

1. 以末节指骨方向定 `top` 与 `across` 两个正交方向。
2. 在指尖上方 `19 mm` 处朝手背方向打 BVH 射线。
3. 7 行 × 9 列网格，行距 `radius*1.80/6`，列宽 `radius*(.32+.38*sin(pi*f)^.62)`。
4. 命中点沿射线方向抬 `0.38 mm`，作为甲片顶点。
5. 任一格未命中就整枚跳过，不要留洞。
6. 甲片整体绑到 `{digit}.03.{side}`，权重 1.0。

验收：甲片到皮肤的最近距离取 95 分位，静止与弯指两态都应 `< 0.8 mm`（实测 0.388 / 0.392 mm）。

## 7. 权重

每个顶点按下列顺序判定，命中即止：

1. **指甲**：直接 1.0 给对应末节。
2. **手皮**：算到 15 条指骨线段的距离，取最近段 `(digit, segment)`：

```python
u       = clamp(((p - a) @ axis) / (axis @ axis), 0, 1)   # 段内进度
reach   = local.x                                          # 沿手轴的位置
finger  = ease((reach - digit_start - .003) / (.028 或拇指 .018))
hand    = ease((reach - .013) / .037)
prev    = .5*ease((.30 - u)/.30) if segment > 0 else 0
next    = .5*ease((u - .70)/.30) if segment < 2 else 0
weights = {
  Forearm : 1 - hand,
  Hand    : hand * (1 - finger),
  digit.segment+1 : hand * finger * (1 - prev - next),
  digit.segment   : hand * finger * prev,
  digit.segment+2 : hand * finger * next,
}
```

3. **头发**：`head = ease((z-1.261)/.203)`，其余给胸。
4. **手臂**：按 `|x|` 与肘高做上臂/前臂/手三段过渡，手段复用同一个 `hand` 曲线。
5. **裙**：整体绑髋，不做布料模拟。
6. **腿**：按高度分髋/大腿/小腿/脚，脚部 `ease((.173-z)/.073)`。

所有分支最后统一：丢掉权重 `< 1e-4` 的项、归一化、按 `(骨骼, 权重)` 分组合并写入顶点组。这样能把百万级 `vertex_groups.add` 调用压到几千次。

## 8. 骨骼朝向

```python
bone.align_roll(frame.dorsal)                      # 手指与手掌
bone.align_roll(frame.dorsal + .40*frame.span)     # 拇指偏转
bone.use_connect = i > 0                           # 指节首尾相接
```

不用 `align_roll` 时，Blender 会按世界 Z 自动算 roll，导致每根手指的局部 X 轴朝向不一致，动画师弯同一角度会得到不同方向。

## 9. 姿态测试（必做）

**隔离测试**：逐根把 `{digit}.02.{side}` 转 `-32°`（局部 X），测量末节顶点位移。

- 该指指尖中位位移应 > 4 mm（实测 22.6–27.5 mm）。
- 其余九指指尖最大位移应 < 0.25 mm（实测 0.0）。

**整手半握**：腕 `±12°`，五指各 `-9/-17/-14`、`-17/-27/-15`、`-22/-33/-16`、`-26/-36/-18`、`-30/-37/-19`。指尖位移应 19–99 mm（实测 19.6–98.5 mm），并渲一张近景看袖口有无穿插。

**注意**：以上都是 Blender 局部坐标下的旋转。目标引擎的骨骼轴向映射不同，未在引擎内实测前不要声称“动画正常”。
