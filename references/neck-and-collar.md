# 颈部、下颌与领口精修

## 1. 先判断轮廓、光照和贴图

固定相机、灯光、色彩管理和曝光，对比前、侧、斜侧视图。使用参考图的共同身高和脚底基线，把正面颈侧宽度、侧面下巴至喉前的拐点、领口遮住皮肤的高度换算成模型尺度。发束遮住的颈部区域属于推断，记录遮挡范围。

遇到暗线或亮边，分别查看普通着色、关闭投射阴影后的着色、基础色和素模法线。用剖面或射线检查两个皮肤面是否争抢前后顺序。开襟、发梢与头部都能给颈部投下窄影。材质色差、真实遮挡和网格折痕各有对应改法。

## 2. 从切口延伸已有皮肤

1. 用材质语义、面邻接和位置范围找到面部皮肤的主要连通分量，检查颈部边界形成的是闭环、开放边链还是多个分支。将有效面与领口碎片分开检查。保留眼、唇、耳及头发锚点。
2. 沿有序边环或边链放样颈部。保留顶圈的共享顶点，逐圈过渡到中段椭圆与向肩胸展开的颈根。用原边切向、弧长和实际角度排布放样点，保持周向次序与最小边距。后颈补面应置于合理的后颈深度。
3. 检查原接缝每条边的面邻接、短边、近重复顶点和相交。保持与脸连续的渐变法线，曲率变化集中在下颌转入喉部的自然位置。自定义法线应在 GLB 回读后再次确认。
4. 从原 UV 的有效肤色采样。在 sRGB 图集与线性顶点色之间显式转换，保持暗部和色相渐变。在靠近旧校服领、发际的边界排除混入的深色或衣料像素。顶点色用于交付前，先确认目标格式确实保留它。
5. 用头、颈、胸三段骨骼做连续的权重过渡。上端随头、颈中段随颈、颈根逐步归到胸骨。调一次转头、一次抬头再测形变，避免用静止合格代替姿态测试。

## 3. 调整外套与针织领口

沿同一套截面拟合翻领和内卷边。外缘移动时，按对应的点同步平移内外层，保持布料厚度和内卷关系。把后领遮挡、袖口等独立层记录为开放结构，检查穿插和可见空隙。若设计上允许局部接触，记录真实位置、范围和来源，区别于穿过表面。

保留物理上合理的衣领、发片投影。若材质底色已正确，针对截面、法线或投影分别验证修复前后的影响。

## 4. 运行局部姿态检查

从 [配置示例](neck-config.example.json) 复制映射，只填写当前项目的骨骼名、导入后的材质名和区域。检测范围使用 Blender 世界坐标、Z 向上，`min` 与 `max` 为面三角中心的筛选边界。对齐两版对象变换，使坐标有可比性。GLB 回读可能拆分 UV 接缝，脚本按可设的距离容差将邻接点识别为共享点。`metres_per_unit` 用于将两版截面测量换算成毫米。

```bash
blender -b --factory-startup --disable-autoexec --python-exit-code 1 \
  --python scripts/blender_neck_qa.py -- \
  --baseline before.blend --file after.glb --config neck-config.json --report neck-qa.json
```

- `regions.skin` 为待查的颈部皮肤。其它名称随资产定义，一般拆分为外套领与针织领。每个区域显式限定边界和材料。
- `pairs` 列出允许检测的相交关系。`[skin, skin]` 自交检查会排除正常共享点的相邻三角；`[skin, coat]` 属于跨部件检查。结果是检测到相交的三角对数，随三角化粒度变化。
- `motions` 为相对文件初始姿态的各骨局部角度。每行动作独立测试，自动加入初始姿态并在检查后恢复原姿态。当前示例包含转头、抬低头和颈骨偏转，先核对目标骨骼局部 XYZ 的含义。缺骨骼、空区域和变形后拓扑不匹配会使该版检查失败。
- `width_sample` 可在指定正交方向和高度用射线测量最前层可见皮肤跨度。步长越大，毫米结果越粗。按实际脸朝向设置 `from_y` 和 `direction_y`，并保持两版一致。
- 区域、姿态和相交对由配置限定。零相交表示这些已测样本通过。完整着色、隐蔽接触的视觉性质、动画极限与游戏引擎表现仍需各自验证。参考 [真实案例](casual-character-case.md)。
